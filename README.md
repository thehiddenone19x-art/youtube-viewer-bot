# youtube-viewer-bot
The entry YouTube tier, built for volume. Live concurrent viewers and video or Shorts views are delivered as lightweight HTTP requests through rotating residential proxies — no browser instance per viewer, no RAM ceiling, no 150 MB Chromium download. That is what lets a single machine hold thousands of sessions at once instead of dozens.

• Raw speed and volume.
• Live stream viewers + video / Shorts views
• Fast raw HTTP — no browser per viewer, so one machine holds THOUSANDS of sessions
• Configurable watch time + heartbeats
• Rotating residential proxies
